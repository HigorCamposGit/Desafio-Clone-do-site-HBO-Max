# 🎬 Desafio Clone do site HBO Max.
Projeto desenvolvido como parte dos desafios práticos de HTML5 e CSS3 da plataforma **DIO (Digital Innovation One)**, para o curso **Formação CSS Web Developer** com foco em estruturação semântica, arquitetura CSS modular e design responsivo.

---

## 🚀 Sobre o Projeto

Este projeto consiste na recriação da página inicial e da tela de login da plataforma de streaming HBO Max. O objetivo principal foi treinar o domínio de seletores CSS, variáveis globais (`:root`), alinhamento avançado com **Flexbox** e **CSS Grid**, além de animações em 3D e responsividade para diferentes dispositivos.

Para manter a estrutura limpa e focar puramente no código e na estilização, **as imagens originais foram substituídas por blocos estilizados e indicadores em texto**.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Marcação semântica das páginas (`index.html` e `login.html`).
- **CSS3**: Estilização modular dividida em três arquivos (`global.css`, `index.css` e `signIn.css`).
- **Flexbox & CSS Grid**: Organização e distribuição fluida dos elementos.
- **Variáveis CSS (`:root`)**: Padronização de cores e temas modernos.
- **Git & GitHub**: Controle de versão e hospedagem do código-fonte.

---
📱 Funcionalidades & Responsividade
Navegação Fixa (sticky nav) com efeito de transparência e links de acesso rápido.

Efeitos 3D nos Planos: Animação de rotação em perspectiva nos cartões de assinatura ao passar o mouse.

Layout Responsivo: Adaptação completa para ecrãs de computadores, tablets e telemóveis utilizando Media Queries. Barra de Rolagem Customizada.
